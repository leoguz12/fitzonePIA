# ADR 0003: CQRS para consultas masivas

| Campo | Contenido |
|---|---|
| **Estado** | ACEPTADA (Fase 2, actualizada) |

## Contexto
El administrador genera reportes de demanda y el instructor consulta el aforo; cargar agregados completos solo para mostrar métricas es innecesario y puede frenar el torniquete.

## Alternativas consideradas
Repositorios de lectura que devuelvan agregados completos (descartado).

## Decisión
Escrituras por el modelo de dominio; **lecturas con SQL directo** (`SqlReadModel`, SQLAlchemy Core) que devuelven diccionarios/DTOs planos con agregaciones en la base de datos. *Cambio respecto a la Fase 2:* se usa SQLAlchemy Core en lugar de Dapper (ver ADR 0004).

## Consecuencias
- **Positivas:** Lecturas rápidas y escalables por separado; el reporte se calcula en SQL.
- **Negativas / riesgos:** Más código (consultas y DTOs); las lecturas no pasan por las reglas del dominio (aceptable: no modifican estado).

## Trazabilidad
US-05 (catálogo), US-08, US-10, US-15
